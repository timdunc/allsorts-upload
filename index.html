All Sorts Upload

A private, single-user tool for publishing videos to one YouTube channel.

What this application does

All Sorts Upload is a private desktop utility that helps its operator publish videos they have already produced to the YouTube channel they own. It runs locally on the operator's own computer. It is not a service, has no public sign-up, and is not offered to or used by anyone other than the channel owner.

What it connects to

The application connects to Google's YouTube Data API and YouTube Analytics API, using OAuth credentials belonging to the channel owner, to do three things:

  • Upload video files, with their titles, descriptions and tags, to the owner's own channel.
  • Read back the resulting video's status, so an upload can be confirmed as complete and public.
  • Read the owner's own performance figures for that channel, to decide what to publish next.

Whose data is involved

Only the channel owner's. The application has a single user — the person who installed it — and accesses only that person's own YouTube channel and analytics. It collects no data from viewers, visitors or any third party, and there is no server that stores anyone's information.
